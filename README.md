# Evelyn Li (LI Yifen)

MSc Low Altitude Economy, The Hong Kong Polytechnic University · BSc Remote Sensing Science and Technology · based in Hong Kong

I work with data — checking it, mostly — and I use AI agents daily to turn requests into workflows I can verify.

## What I do now

As a Student Assistant at PolyU I verify large batches of satellite and CCTV image data for a PhD research team, correct errors and log discrepancies so every handover is traceable. Before that my work was remote sensing and GIS: RTK field surveys, Pix4D photogrammetry, spatial analysis for vertiport siting and fleet capacity planning.

## Projects

**[HKIA Flight Delay Analysis](https://github.com/liyifen0329-evelyn/aae5103-hkia-flight-delay)** — 26,672 departure records from Hong Kong International Airport (1–18 June 2023), analysed for Cathay Pacific, HK Express and Hong Kong Airlines: delay rate, mean and median delay, time-of-day distribution and boarding gate usage. Built in pandas, then re-queried in SQL to cross-validate the same numbers.

**[Drone Flight Analyzer](https://github.com/liyifen0329-evelyn/drone-flight-analyzer)** — A command-line tool that turns a drone flight log into a Markdown safety report. Built with an AI coding agent as reviewer rather than ghostwriter: I type every line, and every result is checked against a hand-count, a second implementation, and input that should break it. That last check is what exposed [issue #1](https://github.com/liyifen0329-evelyn/drone-flight-analyzer/issues/1) — the tool was silently reporting on the wrong file.

## How I work

Verify before trust. Any output — mine or an AI's — gets checked against something I can verify independently: a manual count, a second implementation, or input designed to fail. When I cannot resolve something, I flag it rather than guess.
